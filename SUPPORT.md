# Getting help

- **Using or contributing**: read the repository README and its wiki, then open an issue with the `question` template.
- **Bugs and ideas**: open an issue with the matching template in the right repository ([map of repositories](AGENTS.md#repositories)).
- **Security problems**: never in public, see [SECURITY.md](SECURITY.md).
- **Anything else**: `contact@phorge.fr`.

Phorge is maintained by a very small team; answers can take a few days.
