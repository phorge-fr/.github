# phorge-fr/.github

Organization-wide defaults and project management for [phorge-fr](https://github.com/phorge-fr).

| What | Where |
| --- | --- |
| Organization profile shown on github.com/phorge-fr | [profile/README.md](profile/README.md) |
| Onboarding for humans and AI assistants | [AGENTS.md](AGENTS.md) |
| How issues, pull requests, time and projects work | [GOVERNANCE.md](GOVERNANCE.md) |
| Contributing, conduct, security, support | [CONTRIBUTING.md](CONTRIBUTING.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), [SECURITY.md](SECURITY.md), [SUPPORT.md](SUPPORT.md) |
| Issue and pull request templates applied to every repository | [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE), [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) |
| Shared `pr-governance` check and time tracking | [.github/workflows](.github/workflows), [scripts](scripts) |
| Labels and milestones, synchronized to every repository | [labels.json](labels.json), [milestones.json](milestones.json), [scripts/sync-repos.sh](scripts/sync-repos.sh) |

## Contributing

Every change starts from an issue and goes through a pull request, see [GOVERNANCE.md](GOVERNANCE.md). Planned work is on the public [Roadmap](https://github.com/orgs/phorge-fr/projects/3).

## Security

Report vulnerabilities privately, see [SECURITY.md](SECURITY.md).
